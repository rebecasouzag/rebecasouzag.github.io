# Respostas das entrevistas

Uma nota por sessão: `NN-AAAA-MM-DD.md` (ex.: `01-2026-11-13.md`).

Cada nota registra as perguntas feitas (com o número do roteiro, ex.: 2.3), as respostas nas suas palavras e o que ficou pendente.
Algo que não deve ficar público vai para `privado/` (ignorado pelo git) ou para um arquivo `*.privado.md`.
